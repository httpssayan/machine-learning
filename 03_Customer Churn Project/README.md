# Customer Classification

## Objective
Predict whether a customer will purchase a product using customer information.

## Features
- Gender
- Age
- Estimated Salary

## Target
- Purchased: 0 = No, 1 = Yes

## Model
- Logistic Regression

## Techniques Used
- Exploratory Data Analysis
- Missing Value Handling
- One-Hot Encoding
- Standard Scaling
- Train-Test Split
- Pipeline
- ColumnTransformer
- Logistic Regression
- Probability Prediction
- Classification Evaluation

## Project Workflow
Dataset → EDA → Preprocessing → Logistic Regression → Prediction → Evaluation
